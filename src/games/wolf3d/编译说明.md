# Wolfenstein 3D TCMIPS 移植：编译说明

本代码是 Wolf3D(基于 Wolf4SDL/Wolf3D 引擎源码)在 TCMIPS 平台上的移植。
本文说明：

- 源码组成
- 如何编译为设备 `.tcm` 镜像
- 数据文件如何嵌入
- 关键模块职责

---

## 一、代码结构与数据

```
src/games/wolf3d/
├── wolfmain.cpp             入口 main(TCMIPS shim)：ASCII 控制台选视图大小 → wolf_main()
├── tcm_files.cpp            内存文件层：tcm_fopen/fread/flseek/fclose/fsize
├── tcm_files.h              上述接口声明(TCM_SEEK_* 等常量)
├── tcm_port.h               平台宏改名层(与 nethack 的 tcm_port.h 同思路)
│
├── id_ca.cpp                ild数据管理器(CacheManager)：VSWAP/VGAGRAPH 读取与缓存
├── id_in.cpp                键盘/输入接口
├── id_pm.cpp                板块(Planar)像素操作 → 帧缓冲
├── id_sd.cpp                音频(无声卡时降级为无音频)
├── id_us_1.cpp              启动界面
├── id_vh.cpp / id_vl.cpp    VRAM/位图处理
├── signon.cpp               Blue Stretch 签名界面
├── wl_main.cpp              主循环/MarkTile 等
├── wl_*.cpp                 Wolf3D 游戏逻辑(act1/act2/agent/draw/game/inter/
│                            menu/play/state/text)
│
├── audiowl6.h / gfxv_apo.h / wl_atmos.h / wl_shade.h / wl_cloudsky.h
├── wolfpal.inc              调色板/图形 include 片段
└── version.h
```

数据资源在 `asset/wolf3d/`：

```
asset/wolf3d/
├── wolfdata.h     嵌入数据表声明(9 个 extern 数组)
└── wolfdata.cpp   嵌入数据的字节数组(已提交，构建直接用；由数据打包工具生成)
```

`tcm_files.cpp` 把 `wolfdata.cpp` 的 9 个数组映射为引擎要的文件：

| 引擎文件名(前缀) | 嵌入数组 | 说明 |
|---|---|---|
| `vgahead.` | `wolf_vgahead` | VGA 头(各图块尺寸表) |
| `vgadict.` | `wolf_vgadict` | 图片字典(偏移表) |
| `vgagraph.` | `wolf_vgagraph` | 所有图片数据 |
| `maphead.` | `wolf_maphead` | 地图头(关卡目录) |
| `gamemaps.` | `wolf_gamemaps` | 地图数据 |
| `audiohed.` / `audiot.` | 分别复用 vga/vgadict | 音频未启用(占位) |

注意：引擎获取路径时带 DATADIR 前缀和版本后缀(如 `vgahead.wl1`)，`tcm_fopen`
取文件名尾部 `.` 之前的短名匹配，因此对 `wl1`/`wl6`/`sod` 各版本都兼容。

## 二、设备构建(.tcm 镜像)

### 2.1 工具链(与 NetHack 移植共用)

| 组件 | 路径 | 说明 |
|---|---|---|
| C++ 编译器 | `toolchains/llvm/bin/clang++` | 目标 `mipsel-unknow-elf` |
| 链接器 | `toolchains/llvm/bin/llvm-link-tcmips` | `.bc` 链接为 `.tcm` |
| sysroot | `toolchains/sysroot/` | picolibc，仅 Release |
| CMake 工具链 | `toolchains/cmake/tcmips.toolchain.cmake` | 根 `CMakeLists.txt` 自动引用 |

### 2.2 编译旗标

与 NetHack 相同的基础旗标(`CMakeLists.txt` + 工具链文件统一注入)：

```
--target=mipsel-unknow-elf  -msoft-float -march=mips32r2 -mabi=32 -mno-abicalls
-mllvm -mno-check-zero-division -emit-llvm
-D_FORTIFY_SOURCE=0 -D_DEFAULT_SOURCE=1 -D_GNU_SOURCE=1
-fno-use-cxa-atexit -fno-register-global-dtors-with-atexit -funroll-loops
-Wall -Wextra -Werror=implicit-function-declaration -Werror=implicit-int -Werror=return-type
```

C++ 目标额外带 `-fno-exceptions`(工具链文件对 CXX 统一注入)。

引擎侧无额外 `-D`：不使用 SDL，所有平台差异由 `tcm_files.cpp` / `tcm_port.h` /
`wolfmain.cpp` 隔离。

### 2.3 构建命令

CLion 打开仓库根目录 → **Release** 配置 → 构建 `tcmips_wolf3d`。或命令行：

```bash
export CMAKE="$HOME/.local/share/JetBrains/Toolbox/apps/clion/bin/cmake/linux/x64/bin/cmake"
export PATH="$HOME/.local/share/JetBrains/Toolbox/apps/clion/bin/ninja/linux/x64:$PATH"
$CMAKE -B cmake-build-release
$CMAKE --build cmake-build-release --target tcmips_wolf3d -j8
```

产物：`cmake-build-release/tcmips_wolf3d.tcm`，烧录到设备运行。

根 `CMakeLists.txt` 中目标定义：

```cmake
add_executable(tcmips_wolf3d
  src/games/wolf3d/{wolfmain,id_ca,id_in,id_pm,id_sd,id_us_1,id_vh,id_vl,
                   signon,wl_act1,wl_act2,wl_agent,wl_draw,wl_game,wl_inter,
                   wl_main,wl_menu,wl_play,wl_state,wl_text}.cpp
  src/games/wolf3d/tcm_files.cpp
  asset/wolf3d/wolfdata.cpp
)
target_include_directories(tcmips_wolf3d PRIVATE ${CMAKE_CURRENT_SOURCE_DIR}/asset/wolf3d)
```

## 三、启动流程与运行时行为

1. `wolfmain.cpp::main()` 初始化 ASCII 控制台，显示视图大小选择菜单(1-4)。
2. 用户按键后调 `wolf_main()`，进入 Wolf3D 引擎(Wolf4SDL 主循环子集)。
3. 引擎所有文件访问经 `id_ca.cpp` → `tcm_files.cpp` 内存层完成，无真实磁盘。
4. 全屏渲染由 `id_pm.cpp` 的板块(planar)写入引擎帧缓冲；视图越小(3/4)
   在 4.6MHz 上越流畅。

可用按键：`tcm_port.h` 中调整(方向键/WASD 移动、Ctrl 开火、空格开门、
`P`/`E`/`F` 等 Wolf3D 默认键)。
